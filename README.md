# USED — 중고 통합 검색

모바일 우선 중고물품·중고차 검색 PWA. GitHub Pages의 검색 버튼은 접근 보호된 Vercel 검색 화면으로 이동합니다. 권한이 있는 Vercel 계정으로 로그인한 뒤 같은 출처의 Node 검색 API에서 공개 매물을 정규화해 표시합니다. 공식 제휴 API 서비스가 아니며, 공개 웹페이지 구조나 접근 정책 변경으로 연결이 중단될 수 있습니다.

## 실행

Node 22 이상. 외부 패키지 설치 없이 실행합니다.

```sh
npm test
npm run check
npm run dev
# http://127.0.0.1:4173
```

`src/config.js`는 로컬·Vercel에서 같은 출처 `/api/search`를 사용합니다. GitHub Pages에서 검색하면 검색어·종류·서비스만 보호된 사이트 URL에 전달합니다. 인증·우회 토큰을 코드에 넣지 않습니다. 로그인은 Vercel 자체에서 처리하며 공개 프런트엔드가 보호된 API를 프록시하지 않습니다.

## 화면 구성

홈은 검색어 입력·검색 종류·추천 검색을 제공합니다. 검색 후 별도 결과 화면으로 이동하며 상단 고정 헤더에서 뒤로가기, 재검색, 필터 바텀시트, 정렬을 사용할 수 있습니다. 선택한 필터는 헤더에 말줄임표로 표시합니다. 결과 URL의 검색어·종류·서비스를 새로고침 후 복원하며 브라우저 뒤로/앞으로 이동도 지원합니다.

## 실제 검색 흐름

1. 검색어·종류·서비스를 GET `/api/search?q=...&kind=goods|car&source=all|...`로 전달합니다. 검색어 1~80자만 허용합니다.
2. 공급자별 고정 원문 주소로 제한된 검색 요청을 병렬 실행합니다. 임의 URL을 받는 프록시가 아닙니다.
3. 제목·가격·이미지·직접 원문 링크를 정규화하고, URL/가격/타입 검증과 ID 중복 제거를 수행합니다. 샘플은 실제 응답에서 제외합니다.
4. API 응답에는 `items`, `providers`, `fetchedAt`, `partial`, `limited`가 있습니다. 서비스 일부가 실패하면 성공한 결과와 실패 상태를 함께 반환합니다. 전부 실패하면 502이며 샘플로 대체하지 않습니다.
5. 프런트엔드는 오래된 검색을 취소하고, 수집 결과에 가격·상태·지역·차량 필터를 적용합니다. 찜은 저장 당시 매물 정보를 기기에 보관합니다.
6. 검색·찜 목록의 `원문 보기`는 수집한 실제 매물의 상세 페이지를 새 탭으로 엽니다. 상세 화면에서 실제 주소 확인·복사가 가능하며, 클립보드 사용 불가 시 주소를 선택해 직접 복사할 수 있습니다. 샘플에는 실제 매물 링크를 표시하지 않습니다.

## 검색 범위와 정보 품질

- 각 서비스에서 검색 시 가져올 수 있는 제한된 결과만 제공합니다. 전 웹·전국의 전체 재고나 모든 페이지를 수집하는 검색 인덱스가 아닙니다.
- 필터와 정렬은 가져온 목록에 적용됩니다. 알 수 없는 카테고리·상태·연료·등록일·위치는 추정하거나 채우지 않습니다. 해당 필터 선택 시 정보 없는 매물은 제외됩니다.
- 원문의 갱신일은 등록일과 구분합니다. 최근순은 제공된 등록일·갱신일을 사용하며, 둘 다 없는 매물은 원문 반환 순서를 유지합니다.
- 당근 검색은 원문이 반환하는 지역·검색 범위에 영향을 받습니다. 사용자의 GPS를 원문 검색 범위에 강제로 적용하지 않습니다.
- 위치는 브라우저 메모리에만 보관하고 검색 서버로 보내지 않습니다. 좌표가 제공된 매물만 반경 필터로 확인할 수 있습니다.
- 판매완료·삭제·가격변경은 수집 이후 달라질 수 있습니다. 원문에서 최종 확인해야 합니다.
- API 결과는 CDN에서 최대 60초 재사용될 수 있습니다. 서비스 워커는 실제 검색 응답을 오프라인 저장하지 않습니다.
- KB차차차는 제조사·대표모델명을 공식 코드 목록에서 찾은 경우 첫 페이지 매물을 수집합니다. K Car는 공개 웹 클라이언트의 검색 요청 형식을 사용해 직영차 결과 일부를 수집합니다.

## 배포 구조

화면은 GitHub Pages (`main`, root)로 유지합니다. 검색 API는 Vercel `used-search-api` 프로젝트의 `api/search.js`에서 실행합니다. Node 22+, 서울 리전, 함수 최대 25초, 공급자 요청 전체 18초 제한. 기존 GitHub 인증에는 workflow 권한이 없으므로 Actions 파일을 추가하지 않습니다.

사용자가 접근 보호 유지를 선택했습니다. Vercel Authentication을 유지하고 화면과 API를 동일 보호 도메인 https://used-search-api.vercel.app/ 에 배치합니다. GitHub Pages는 로그인 후 실제 검색으로 이동하는 진입점입니다. 로그인하더라도 프로젝트 접근 권한이 있어야 합니다. 공유 링크·우회 토큰·인증 해제는 사용하지 않습니다. 찜 데이터는 사이트별 브라우저 저장소에 보관되며 GitHub Pages와 Vercel 간 자동 이전되지 않습니다.

프로젝트의 `ssoProtection.deploymentType`은 `all`입니다. 기본 보호 설정은 프로덕션 별칭을 제외할 수 있으므로 배포마다 기본 도메인과 API의 비로그인 접근 차단을 확인합니다. 2026-11-01 확인 시 API는 302 로그인 이동을 반환했습니다.

배포 파일: `api/`, `server/handler.mjs`, `server/providers/`, `src/search.js`, `package.json`, `vercel.json`. 보호된 앱 배포에는 `index.html`, `src/`, `assets/`, `data/`, manifest와 service worker도 포함합니다.

## 검증

`npm test`: 검색·복합 필터·거리 계산·공급자 파싱·오류·부분 성공·중복/샘플 차단 검증.
`npm run check`: 프런트엔드와 API 문법 검사.

실제 네트워크 검증은 원문 접근 상태에 따라 달라지므로 단위 테스트에서 네트워크를 강제하지 않습니다. 배포 전 실제 키워드로 결과의 제목·가격·원문 URL을 확인합니다.

2026-11-01 검증: 로컬에서 중고물품 4개 서비스와 자동차 3개 서비스의 실제 응답을 확인했습니다. Vercel 배포에서는 중고물품 4개 서비스·KB차차차·K Car 응답을 확인했으나 엔카 연결은 실패했습니다. 원문 서비스가 배포 환경에서 응답하는지에 따라 검색 가능 범위가 달라지며, 현재 배포에서 7개 서비스가 모두 정상이라는 보장은 하지 않습니다. 연결 오류는 화면에 서비스별로 표시하고 성공한 결과는 유지합니다.

## 개인정보·디자인

찜은 localStorage에만 저장되며 기기 간 동기화되지 않습니다. 검색어와 선택 서비스는 API와 원문 서비스에 전달됩니다. 위치는 방문 중 브라우저에서만 사용합니다. 구매·결제·채팅은 제공하지 않습니다. 토스 공개 디자인 원칙을 참고한 독립 UI이며 공식 TDS 패키지 또는 제휴 서비스는 아닙니다. 샘플 체험은 사용자가 직접 선택할 때만 표시합니다.
