# USED — 중고 통합 검색

모바일 우선 중고물품·중고차 검색 PWA. 홈·검색·상세는 접근 보호된 `https://used-search-api.vercel.app/`에서 제공합니다. GitHub Pages는 접속 즉시 같은 Vercel 앱으로 이동하는 이전 주소입니다. 권한이 있는 Vercel 계정으로 로그인한 뒤 같은 출처의 Node 검색 API에서 공개 매물을 정규화해 표시합니다. 공식 제휴 API 서비스가 아니며, 공개 웹페이지 구조나 접근 정책 변경으로 연결이 중단될 수 있습니다.

## 실행

Node 22 이상. 외부 패키지 설치 없이 실행합니다.

```sh
npm test
npm run check
npm run dev
# http://127.0.0.1:4173
```

`src/config.js`는 로컬·Vercel에서 같은 출처 `/api/search`를 사용합니다. `src/entry.js`는 GitHub Pages 접속 시 앱을 실행하지 않고 고정된 Vercel 주소로 이동합니다. 검색어·종류·서비스·상세 ID·화면·설치 안내처럼 검증한 앱 상태만 전달하며, 인증·공유 토큰·임의 이동 주소·해시·위치 정보는 전달하지 않습니다. Vercel과 로컬에서는 같은 출처의 앱을 실행하므로 홈에서 검색할 때 다른 도메인으로 이동하지 않습니다. 인증·우회 토큰을 코드에 넣지 않습니다. 로그인은 Vercel 자체에서 처리하며 공개 프런트엔드가 보호된 API를 프록시하지 않습니다.

## 화면 구성

홈은 검색어 입력·검색 종류·추천 검색을 제공합니다. 검색 후 별도 결과 화면으로 이동하며 상단 고정 헤더에서 뒤로가기, 재검색, 필터 바텀시트, 정렬을 사용할 수 있습니다. 선택한 필터는 헤더에 말줄임표로 표시합니다. 결과 URL의 검색어·종류·서비스를 새로고침 후 복원하며 브라우저 뒤로/앞으로 이동도 지원합니다. 하단에 배포 버전과 새로고침 버튼을 표시합니다. 새로고침은 현재 검색 화면·필터·정렬과 찜 저장을 유지하고, 서비스 워커 업데이트를 최대 1.5초 확인한 뒤 페이지를 다시 불러옵니다. 버전은 날짜 대신 `주.부.수정` 형식의 시맨틱 버전으로 표시하며, 현재 버전은 `1.2.2`입니다. 호환되지 않는 큰 변경은 주 버전(예: `2.0.0`), 기존 동작을 유지하는 기능 추가는 부 버전(예: `1.2.0`), 오류 수정은 수정 버전(예: `1.1.1`)을 올립니다. 배포할 때 `src/version.js`와 `package.json`의 버전을 맞추고, `index.html`·모듈 import의 자산 버전 및 `sw.js`의 캐시 버전도 함께 갱신합니다.

## 실제 검색 흐름

1. 검색어·종류·서비스를 GET `/api/search?q=...&kind=goods|car&source=all|...`로 전달합니다. 검색어 1~80자만 허용합니다.
2. 공급자별 고정 원문 주소로 제한된 검색 요청을 병렬 실행합니다. 임의 URL을 받는 프록시가 아닙니다.
3. 제목·가격·이미지·직접 원문 링크를 정규화하고, URL/가격/타입 검증과 ID 중복 제거를 수행합니다.
4. API 응답에는 `items`, `providers`, `fetchedAt`, `partial`, `limited`가 있습니다. 서비스 일부가 실패하면 성공한 결과와 실패 상태를 함께 반환합니다. 전부 실패하면 502와 연결 오류를 반환합니다.
5. 프런트엔드는 오래된 검색을 취소하고, 수집 결과에 가격·상태·지역·차량 필터를 적용합니다. 찜은 저장 당시 매물 정보를 기기에 보관합니다.
6. 검색·찜 목록의 `원문 보기`는 수집한 실제 매물의 상세 페이지를 새 탭으로 엽니다. 상세 화면에서 실제 주소 확인·복사가 가능하며, 클립보드 사용 불가 시 주소를 선택해 직접 복사할 수 있습니다.

## 매물 상세 페이지

모든 매물의 `상세 보기`는 바텀시트 대신 `?view=detail&item=매물ID` 페이지로 이동합니다. 상단에는 반투명 블러 효과의 리퀴드 글라스 헤더와 뒤로가기 버튼, 하단에는 찜·원문 보기 버튼을 표시합니다. 검색 결과에서 들어온 경우 뒤로가면 검색 조건·정렬·현재 목록·스크롤 위치를 복원합니다. 새로고침 시 같은 브라우저의 history snapshot을 검증해 복원하며, KB 실제 매물은 숫자 ID로 직접 상세 조회도 가능합니다. 복원 정보가 없는 다른 서비스의 매물은 다시 검색하도록 안내합니다.

KB 사진 갤러리는 화살표·썸네일·키보드·스와이프 이동 때 활성 썸네일을 가운데 정렬합니다. 첫·마지막 사진도 가운데 놓이도록 실제 너비에 맞춘 여백을 사용하고, 화면 너비가 바뀌면 선택 사진을 유지해 다시 정렬합니다. 썸네일 정렬은 가로 영역만 이동하며 페이지의 세로 스크롤은 움직이지 않습니다. 필터·지역 설정은 기존 바텀시트를 사용합니다.

## KB차차차 상세 조회

실제 KB차차차 매물의 `매물 살펴보기`를 열면 GET `/api/detail?source=kb&id=차량번호`로 원문의 공개 상세 정보를 추가 조회합니다. 검색 목록 전체에 상세 요청을 보내지 않습니다. 같은 매물의 사진, 가격, 기본 제원, 원문에 명시된 옵션, 성능점검·보험 이력, 판매 상사와 지역, 확인 시각을 구분해 보여줍니다. 공개 원문에 없는 정보는 추정하지 않으며, 보험 이력과 공통 홍보 문구를 차량의 무사고 판정으로 바꾸지 않습니다.

상세 API는 KB차차차 고정 호스트와 숫자 매물 ID만 허용하고 임의 URL은 받지 않습니다. 서버 조회는 9초·2MB로 제한합니다. 브라우저는 화면을 닫거나 이동하면 요청을 취소하고, 조회 실패 시 기존 검색 정보와 원문 링크를 유지합니다. KB차차차 외 서비스는 기존 기본 상세 정보를 제공합니다. 상세 조회도 기존 Vercel 접근 보호를 따릅니다.

2026-11-01 상세 검증: 제공된 매물 28882930의 로컬 실제 검색 → 상세 API → 모바일 화면 흐름에서 사진 19장·기본정보 12개·주요옵션 6개·보험이력 4건 등을 확인했습니다. Vercel 미국 빌드 환경(iad1)에서는 같은 원문이 HTTP 200의 89바이트 `ERROR` 페이지를 반환했습니다. 운영 함수의 서울 환경(icn1)에서 로그인한 사용자의 상세 조회 성공은 아직 확인하지 못했으며, 원문 응답에 따라 실패 안내가 나타날 수 있습니다.

## 검색 범위와 정보 품질

- 각 서비스에서 검색 시 가져올 수 있는 제한된 결과만 제공합니다. 전 웹·전국의 전체 재고나 모든 페이지를 수집하는 검색 인덱스가 아닙니다.
- 필터와 정렬은 가져온 목록에 적용됩니다. 알 수 없는 카테고리·상태·연료·등록일·위치는 추정하거나 채우지 않습니다. 해당 필터 선택 시 정보 없는 매물은 제외됩니다.
- 원문의 갱신일은 등록일과 구분합니다. 최근순은 제공된 등록일·갱신일을 사용하며, 둘 다 없는 매물은 원문 반환 순서를 유지합니다.
- 당근 검색은 원문이 반환하는 지역·검색 범위에 영향을 받습니다. 사용자의 GPS를 원문 검색 범위에 강제로 적용하지 않습니다.
- 위치는 브라우저 메모리에만 보관하고 검색 서버로 보내지 않습니다. 좌표가 제공된 매물만 반경 필터로 확인할 수 있습니다.
- 판매완료·삭제·가격변경은 수집 이후 달라질 수 있습니다. 원문에서 최종 확인해야 합니다.
- API 결과는 CDN에서 최대 60초 재사용될 수 있습니다. 서비스 워커는 실제 검색 응답을 오프라인 저장하지 않습니다.
- KB차차차는 제조사·대표모델명을 공식 코드 목록에서 찾은 경우 첫 페이지 매물을 수집합니다. K Car는 공개 웹 클라이언트의 검색 요청 형식을 사용해 직영차 결과 일부를 수집합니다.

## 배포 구조

홈·검색·상세 화면과 API는 Vercel `used-search-api` 프로젝트에서 실행합니다. GitHub Pages (`main`, root)는 기존 링크를 Vercel 앱으로 전달하는 진입점입니다. 검색 API는 `api/search.js`이며 Node 22+, 서울 리전, 함수 최대 25초, 공급자 요청 전체 18초 제한입니다. 기존 GitHub 인증에는 workflow 권한이 없으므로 Actions 파일을 추가하지 않습니다.

사용자가 접근 보호 유지를 선택했습니다. Vercel Authentication을 유지하고 화면과 API를 동일 보호 도메인 https://used-search-api.vercel.app/ 에 배치합니다. GitHub Pages는 홈부터 보호된 Vercel 앱으로 즉시 이동하는 진입점입니다. 로그인하더라도 프로젝트 접근 권한이 있어야 합니다. 공유 링크·우회 토큰·인증 해제는 사용하지 않습니다. 찜 데이터는 사이트별 브라우저 저장소에 보관되며 GitHub Pages와 Vercel 간 자동 이전되지 않습니다.

프로젝트의 `ssoProtection.deploymentType`은 `all`입니다. 기본 보호 설정은 프로덕션 별칭을 제외할 수 있으므로 배포마다 기본 도메인과 API의 비로그인 접근 차단을 확인합니다. 2026-11-01 확인 시 API는 302 로그인 이동을 반환했습니다.

배포 파일: `api/`, `server/handler.mjs`, `server/providers/`, `src/search.js`, `package.json`, `vercel.json`. 보호된 앱 배포에는 `index.html`, `src/`, `assets/`, manifest와 service worker도 포함합니다.

## 검증

`npm test`: 검색·복합 필터·거리 계산·공급자 파싱·오류·부분 성공·중복 제거·이전 미리보기 기록 차단 검증.
`npm run check`: 프런트엔드와 API 문법 검사.

실제 네트워크 검증은 원문 접근 상태에 따라 달라지므로 단위 테스트에서 네트워크를 강제하지 않습니다. 배포 전 실제 키워드로 결과의 제목·가격·원문 URL을 확인합니다.

2026-11-01 검증: 로컬에서 중고물품 4개 서비스와 자동차 3개 서비스의 실제 응답을 확인했습니다. Vercel 배포에서는 중고물품 4개 서비스·KB차차차·K Car 응답을 확인했으나 엔카 연결은 실패했습니다. 원문 서비스가 배포 환경에서 응답하는지에 따라 검색 가능 범위가 달라지며, 현재 배포에서 7개 서비스가 모두 정상이라는 보장은 하지 않습니다. 연결 오류는 화면에 서비스별로 표시하고 성공한 결과는 유지합니다.

같은 날 클라우드 진단에서 엔카 공개 검색 요청의 HTTP 407을 확인했습니다. Node Fetch는 이 상태를 일반 네트워크 오류로 숨기므로 엔카 요청만 동일 URL의 표준 HTTPS GET으로 상태를 확인합니다. TLS 검증을 유지하고 리디렉션·재시도·인증 우회 없이 403/407/429를 `unavailable`로 표시합니다. 응답 크기는 2MB, 대기시간은 9초로 제한합니다. 이는 접근 제한 해제가 아니며 엔카의 배포 서버 수집은 아직 미해결입니다. 정식 데이터 이용 권한 또는 원문/중간 네트워크의 정책 확인이 필요합니다.

## 개인정보·디자인

아이폰의 주소창 없는 실행은 `display: standalone`으로 제공합니다. 실제 검색을 사용하는 홈 화면 아이콘은 로그인한 `https://used-search-api.vercel.app/`에서 추가해야 합니다. 기존 GitHub Pages 아이콘은 시작 시 다른 도메인으로 이동하므로 iOS가 브라우저 컨트롤을 표시할 수 있습니다. 기존 아이콘의 설치 주소는 코드로 바꿀 수 없으며 새 아이콘을 추가해야 합니다. 홈의 ‘주소창 없이 앱으로 사용하기’가 올바른 설치 위치로 안내합니다. 로그인 및 외부 매물 원문은 브라우저 컨트롤이 나타날 수 있습니다. 보호 설정과 앱의 검색·필터·뒤로가기·하단 메뉴는 유지합니다.

찜은 localStorage에만 저장되며 기기 간 동기화되지 않습니다. 검색어와 선택 서비스는 API와 원문 서비스에 전달됩니다. 위치는 방문 중 브라우저에서만 사용합니다. 구매·결제·채팅은 제공하지 않습니다. 토스 공개 디자인 원칙을 참고한 독립 UI이며 공식 TDS 패키지 또는 제휴 서비스는 아닙니다.

보호된 앱의 manifest는 `crossorigin="use-credentials"`로 불러옵니다. 같은 도메인의 기존 로그인 쿠키를 포함해 설치 설정을 읽으며, 인증 보호를 우회하거나 공개하지 않습니다.

## 엔카 브라우저 직접 조회 복구

Vercel의 정상 검색 응답에서 엔카 연결 실패가 확인되면, 브라우저가 같은 엔카 공개 검색 API를 `credentials: omit`의 CORS GET으로 한 번 조회합니다. 요청은 9초·2MB로 제한하고 검색 취소/화면 이동 시 함께 취소합니다. 쿠키·인증정보·우회 프록시를 사용하지 않습니다. 성공한 실제 매물을 동일한 검증·중복 제거·키워드 필터를 거쳐 KB차차차/K Car 결과와 합치며, 실패하면 기존 결과와 서비스별 연결 안내를 유지합니다. 로그인 실패(401/403), 요청 제한(429), 잘못된 서버 응답일 때는 이 복구를 실행하지 않습니다.

2026-11-01 검증: USED Origin의 공개 API 응답이 `Access-Control-Allow-Origin: *`를 허용함을 확인했고, 실제 브라우저에서도 `xf` 요청이 CORS HTTP 200과 105건의 전체 수를 반환했습니다. 이는 해당 시점·검증 네트워크에서의 조회 성공이며 엔카 정책이나 사용자 네트워크에 따라 달라질 수 있습니다. 서버 경로의 407 자체를 해결한 것은 아닙니다.

로컬 통합 검증에서는 서버의 엔카 실패 응답만 재현하고, 엔카 브라우저 요청과 KB차차차/K Car 서버 요청은 실제 서비스에 연결했습니다. `xf`는 엔카 30개·KB차차차 18개·K Car 0개, `그랜저`는 엔카 29개·KB차차차 30개·K Car 30개가 동일 목록에 표시됐습니다. 자동 테스트 90개와 구문 검사를 통과했습니다. 보호된 운영 앱의 사용자 아이폰 환경은 별도 확인이 필요합니다.
