# USED — 중고 통합 검색

모바일 우선 중고물품·중고차 검색 PWA. 홈·검색·상세는 로그인 없이 이용하는 `https://used-search-api.vercel.app/`에서 제공합니다. GitHub Pages는 접속 즉시 같은 Vercel 앱으로 이동하는 이전 주소입니다. 같은 출처의 Node 검색 API에서 공개 매물을 정규화해 표시합니다. 공식 제휴 API 서비스가 아니며, 공개 웹페이지 구조나 접근 정책 변경으로 연결이 중단될 수 있습니다.

## 실행

Node 22 이상. 외부 패키지 설치 없이 실행합니다.

```sh
npm test
npm run check
npm run dev
# http://127.0.0.1:4173
```

`src/config.js`는 로컬·Vercel에서 같은 출처 `/api/search`를 사용합니다. `src/entry.js`는 GitHub Pages 접속 시 앱을 실행하지 않고 고정된 Vercel 주소로 이동합니다. 검색어·종류·서비스·상세 ID·화면·설치 안내처럼 검증한 앱 상태만 전달하며, 인증·공유 토큰·임의 이동 주소·해시·위치 정보는 전달하지 않습니다. Vercel과 로컬에서는 같은 출처의 앱을 실행하므로 홈에서 검색할 때 다른 도메인으로 이동하지 않습니다. 인증·우회 토큰을 코드에 넣지 않습니다. 운영 도메인은 공개하고 개발·개별 배포 URL은 Vercel Standard Protection으로 보호합니다.

## 화면 구성

홈 카피는 “좋은매물 한곳에서”이며, 큰 중고물품·중고차 선택 버튼과 중앙 검색바, 세 가지 추천 검색으로 구성합니다. 종류 선택 아이콘은 아이폰·기아 레이를 형상화한 자체 3D 모델을 사용합니다. 받침대와 함께 12초마다 360도 회전하며 홈이 숨겨지거나 화면 밖으로 나가면 렌더링을 중지합니다. 동작 줄이기를 켜거나 WebGL을 사용할 수 없으면 모델에서 생성한 정지 포스터를 표시합니다. Three.js는 MIT 라이선스로 로컬에 고정 버전을 저장하고, 3D 코드는 스플래시 완료 후 필요할 때만 불러옵니다. 하단에는 선택한 종류에 맞는 공식 서비스 로고를 원색·비율 그대로 표시합니다. 로고 표시 크기는 기존의 50%로 줄이고 같은 크기의 셀과 간격을 사용해 한 줄로 중앙 정렬합니다. 원본 출처는 `assets/service-logos/`의 출처 문서에 기록하며 로고도 오프라인 캐시에 포함합니다. 상단 공유 버튼은 공개 공유 진입 주소만 공유하며, 네이티브 공유를 지원하지 않으면 링크 복사 또는 수동 복사를 제공합니다. 시작 화면은 앱 초기화 단계에 따라 진행률 숫자와 막대를 0~100%까지 표시하며, 외부 매물 조회 완료를 기다리지 않습니다. 초기화 실패 시 재시작을 제공하고 동작 줄이기 설정을 지원합니다. 검색 후 별도 결과 화면으로 이동하며 상단 고정 헤더에 뒤로가기, 재검색, 필터 버튼만 제공합니다. 결과에는 종류·서비스 탭과 개별 가격·내 주변·정렬 버튼을 두지 않습니다. 홈에서 선택한 종류가 이어지는 검색에도 유지되며 서비스 선택·지역·가격·정렬은 모두 필터 시트에 모읍니다. 가격·지역·정렬만 변경하면 추가 API 호출 없이 기존 목록에 적용합니다. 선택한 필터는 헤더에 말줄임표로 표시합니다. 결과 URL의 검색어·종류·서비스를 새로고침 후 복원하며 브라우저 뒤로/앞으로 이동도 지원합니다. 상세 뒤로가기는 진행 중인 상세 요청을 즉시 정리하고 중복 탭을 방지합니다. 스크롤마다 History API를 호출하지 않으며, 기록 저장이 거절되어도 뒤로가기 동작은 실행합니다. 하단에 배포 버전과 새로고침 버튼을 표시합니다. 새로고침은 현재 검색 화면·필터·정렬과 찜 저장을 유지하고, 서비스 워커 업데이트를 최대 1.5초 확인한 뒤 페이지를 다시 불러옵니다. 버전은 날짜 대신 `주.부.수정` 형식의 시맨틱 버전으로 표시하며, 현재 버전은 `1.7.0`입니다. 호환되지 않는 큰 변경은 주 버전(예: `2.0.0`), 기존 동작을 유지하는 기능 추가는 부 버전(예: `1.2.0`), 오류 수정은 수정 버전(예: `1.1.1`)을 올립니다. 배포할 때 `src/version.js`와 `package.json`의 버전을 맞추고, `index.html`·모듈 import의 자산 버전 및 `sw.js`의 캐시 버전도 함께 갱신합니다.

모바일 글자는 본문 16px·보조 설명 14px을 기준으로 사용하고 제목·가격은 더 크게 표시합니다. 숫자 배지와 NEW 표시는 12px입니다. 하단 메뉴는 홈·찜·둘러보기 아이콘을 사용하며 접근성 이름과 현재 선택 상태를 제공합니다. 찜 배지는 0개면 숨기고 100개 이상은 `99+`로 표시하되 스크린리더에는 실제 개수를 전달합니다. 찜·둘러보기 메뉴 화면에는 뒤로가기 대신 화면 제목을 표시하고, 검색 결과·매물 상세의 뒤로가기는 유지합니다. 찜 화면은 중복 제목·설명·검색 도구 없이 저장한 매물 전체를 최근 찜한 순서로 보여 주며, 검색 종류·서비스·필터·지역·정렬의 영향을 받지 않습니다. 둘러보기는 이전 검색 조건과 관계없이 7개 서비스의 시작 화면을 제공하며 헤더와 본문 사이를 32px 띄웁니다.

## 공유 미리보기

홈 공유 버튼은 `https://uxidesigner-ux.github.io/secondhand/share/`를 사용합니다. 이 정적 페이지는 OG·Twitter 메타태그와 공개 공유 이미지를 제공한 뒤 브라우저에서 보호된 Vercel 홈으로 이동합니다. 공유 링크에는 검색어·위치·인증 정보를 넣지 않습니다. Vercel의 로그인 보호는 유지하며, 보호된 Vercel 주소를 직접 복사하는 경우 외부 미리보기 수집기가 로그인 화면을 볼 수 있습니다.

공유 이미지는 `assets/share/used-share-1.5.0.png`(1200×630)입니다. `scripts/generate-share-card.swift`가 기존 앱아이콘 SVG의 로고 윤곽과 파란 도트를 그대로 재사용하고 “원하는 제품, 일단 찾아봐” 문구를 렌더링합니다. 원본 SVG도 함께 보관합니다. 이미지 주소에 버전을 포함해 이전 이미지 캐시와 구분합니다. 메타태그는 JavaScript 실행 없이 초기 HTML에서 읽힙니다. 형식은 [Open Graph 규격](https://ogp.me/)을 따릅니다.

배포 시 GitHub Pages 빌드 완료 후 공유 페이지와 이미지가 로그인 없이 HTTP 200을 반환하는지 별도로 확인합니다. 실제 채팅앱의 미리보기 갱신 시점과 모양은 해당 앱에 따릅니다.

## 실제 검색 흐름

1. 검색어·종류·서비스를 GET `/api/search?q=...&kind=goods|car&source=all|...`로 전달합니다. 검색어 1~80자만 허용합니다.
2. 공급자별 고정 원문 주소로 제한된 검색 요청을 병렬 실행합니다. 임의 URL을 받는 프록시가 아닙니다.
3. 제목·가격·이미지·직접 원문 링크를 정규화하고, URL/가격/타입 검증과 ID 중복 제거를 수행합니다.
4. API 응답에는 `items`, `providers`, `fetchedAt`, `partial`, `limited`가 있습니다. 서비스 일부가 실패하면 성공한 결과와 실패 상태를 함께 반환합니다. 전부 실패하면 502와 연결 오류를 반환합니다.
5. 프런트엔드는 오래된 검색을 취소하고, 수집 결과에 가격·상태·지역·차량 필터를 적용합니다. 찜은 저장 당시 매물 정보를 기기에 보관합니다.
6. 검색·찜 목록의 `원문 보기`는 수집한 실제 매물의 상세 페이지를 새 탭으로 엽니다. 상세 화면에서 실제 주소 확인·복사가 가능하며, 클립보드 사용 불가 시 주소를 선택해 직접 복사할 수 있습니다.

## 매물 상세 페이지

모든 매물의 `상세 보기`는 바텀시트 대신 `?view=detail&item=매물ID` 페이지로 이동합니다. 상단에는 반투명 블러 효과의 리퀴드 글라스 헤더와 뒤로가기 버튼, 하단에는 찜·원문 보기 버튼을 표시합니다. 검색 결과에서 들어온 경우 뒤로가면 검색 조건·정렬·현재 목록·스크롤 위치를 복원합니다. 새로고침 시 같은 브라우저의 history snapshot을 검증해 복원하며, 엔카·KB차차차·K Car는 서비스별 매물 ID로 직접 상세 조회도 가능합니다. 복원 정보가 없는 중고물품은 다시 검색하도록 안내합니다.

차량 사진 갤러리는 화살표·썸네일·키보드·스와이프 이동 때 활성 썸네일을 가운데 정렬합니다. 첫·마지막 사진도 가운데 놓이도록 실제 너비에 맞춘 여백을 사용하고, 화면 너비가 바뀌면 선택 사진을 유지해 다시 정렬합니다. 썸네일 정렬은 가로 영역만 이동하며 페이지의 세로 스크롤은 움직이지 않습니다. 필터·지역 설정은 기존 바텀시트를 사용합니다.

## 차량 상세 조회

엔카·KB차차차·K Car의 `매물 살펴보기`를 열면 GET `/api/detail?source=encar|kb|kcar&id=매물ID`로 원문의 공개 상세 정보를 추가 조회합니다. 검색 목록 전체에 상세 요청을 보내지 않습니다. 같은 매물의 사진, 가격, 기본 제원, 원문에 명시된 옵션, 성능점검·보험 이력, 판매 상사와 지역, 확인 시각을 구분해 보여줍니다. 공개 원문에 없는 정보는 추정하지 않으며, 보험 이력과 공통 홍보 문구를 차량의 무사고 판정으로 바꾸지 않습니다.

상세 API는 서비스별 고정 공식 호스트와 검증된 매물 ID만 허용하고 임의 URL은 받지 않습니다. 엔카·KB차차차는 숫자 ID, K Car는 `EC`로 시작하는 차량 코드를 사용합니다. 서버 조회는 9초·2MB로 제한합니다. 브라우저는 화면을 닫거나 이동하면 요청을 취소하고, 조회 실패 시 기존 검색 정보와 원문 링크를 유지합니다. 중고물품은 기존 검색 정보 기반의 상세 화면을 제공합니다. 상세 조회도 무료 운영용 호출 제한과 10분 캐시를 적용합니다.

엔카는 공개 상세 HTML의 `__PRELOADED_STATE__.cars.base`를 JSON으로만 읽고, 공개 옵션 사전·성능점검·엔카진단 응답을 추가 확인합니다. 보강 요청이 실패하면 확인한 사진·제원·선택 옵션을 유지합니다. 엔카 옵션 코드 중 그룹과 개별 옵션의 번호가 겹치므로 개별 옵션만 매칭합니다. 상세 API가 정확한 차량 ID와 `DETAIL_UPSTREAM_UNAVAILABLE`를 담은 502/503을 반환할 때만 브라우저에서 공식 공개 JSON을 쿠키 없이 조회합니다. 401/403·429·로그인 HTML·잘못된 응답에는 대체 요청을 하지 않습니다. 서버 및 브라우저 경로는 각각 9초·합산 2MB로 제한하고, UI 전체 대기는 20초입니다.

K Car는 공개 상세 페이지가 사용하는 `/bc/car-info-detail-of-ng`의 선택 차량 응답을 읽습니다. 상세에 표시된 할인 가격 또는 판매 가격(만원)을 원으로 변환하며 월 리스·렌트 견적을 구매 가격으로 표시하지 않습니다. `optList`는 장착 옵션 목록이고 `gneptYn`은 순정 여부이므로 비순정도 구분해서 표시합니다. 배너·다른 차량 사진은 제외하고 같은 차량의 사진만 최대 40장 표시합니다. 보험이력과 사고진단은 별도 항목이며, 없는 값은 추정하지 않습니다.

## 검색 범위와 정보 품질

- 각 서비스에서 검색 시 가져올 수 있는 제한된 결과만 제공합니다. 전 웹·전국의 전체 재고나 모든 페이지를 수집하는 검색 인덱스가 아닙니다.
- 필터와 정렬은 가져온 목록에 적용됩니다. 알 수 없는 카테고리·상태·연료·등록일·위치는 추정하거나 채우지 않습니다. 해당 필터 선택 시 정보 없는 매물은 제외됩니다.
- 원문의 갱신일은 등록일과 구분합니다. 최근순은 제공된 등록일·갱신일을 사용하며, 둘 다 없는 매물은 원문 반환 순서를 유지합니다.
- 당근 검색은 원문이 반환하는 지역·검색 범위에 영향을 받습니다. 사용자의 GPS를 원문 검색 범위에 강제로 적용하지 않습니다.
- 위치는 이 탭의 방문 기록에 보관해 화면 이동·새로고침 때 복원하며 외부로 보내지 않습니다. 좌표가 제공된 매물만 반경 필터로 확인할 수 있습니다.
- 판매완료·삭제·가격변경은 수집 이후 달라질 수 있습니다. 원문에서 최종 확인해야 합니다.
- 검색은 각 캐시 계층에서 3분, 상세는 10분 재사용될 수 있습니다. 캐시 계층이 겹치므로 원문 확인 시각을 함께 표시합니다. 서비스 워커는 실제 검색 응답을 오프라인 저장하지 않습니다.
- KB차차차는 제조사·대표모델명을 공식 코드 목록에서 찾은 경우 첫 페이지 매물을 수집합니다. K Car는 공개 웹 클라이언트의 검색 요청 형식을 사용해 직영차 결과 일부를 수집합니다.

## 배포 구조

홈·검색·상세 화면과 API는 Vercel `used-search-api` 프로젝트에서 실행합니다. GitHub Pages (`main`, root)는 기존 링크를 Vercel 앱으로 전달하는 진입점입니다. 검색 API는 `api/search.js`이며 Node 22+, 서울 리전, 함수 최대 25초, 공급자 요청 전체 18초 제한입니다. 기존 GitHub 인증에는 workflow 권한이 없으므로 Actions 파일을 추가하지 않습니다.

v1.6.0부터 사용자의 공개 요청에 따라 운영 도메인을 로그인 없이 제공합니다. 프로젝트의 `ssoProtection.deploymentType`은 `prod_deployment_urls_and_all_previews`로 설정해 개발 및 개별 배포 URL 보호를 유지합니다. 공유·인증 우회 토큰을 클라이언트에 넣지 않습니다.

현재 Hobby 무료 요금제를 유지하며 유료 API·DB·애드온을 추가하지 않습니다. 무료 한도를 넘으면 이용이 제한될 수 있습니다. 코드의 호출 제한은 인스턴스별 보조 장치이며 전역 과금 상한이 아닙니다. 추가 WAF 규칙은 적용하지 않았습니다. 수치·한계·중단 방법은 [무료 운영과 비용 제어 설계](docs/cost-controls.md)를 참고하세요.

배포 파일: `api/`, `server/handler.mjs`, `server/providers/`, `src/search.js`, `package.json`, `vercel.json`. 앱 배포에는 `index.html`, `src/`, `assets/`, manifest와 service worker도 포함합니다.

## 검색 요청 안내

v1.6.1부터 서버의 분당 IP 요청 한도 80% 이상에서 결과 상단에 작은 안내를 표시합니다. 12회 중 10번째부터 안내하며, 같은 구간에서 닫으면 반복 표시하지 않습니다. 429에서는 남은 대기 시간을 표시하고 같은 검색 범위의 이전 결과를 유지합니다. 캐시 결과·필터·원문 링크는 계속 이용할 수 있고 시간이 지나도 자동 재검색하지 않습니다. 이용자별 안내를 담은 응답은 브라우저와 CDN에 저장하지 않으며, 일반 검색 캐시는 유지합니다. 전체 Vercel 무료 사용량 경고는 아닙니다.

## 검증

`npm test`: 검색·복합 필터·거리 계산·공급자 파싱·오류·부분 성공·중복 제거·이전 미리보기 기록 차단 검증.
`npm run check`: 프런트엔드와 API 문법 검사.

실제 네트워크 검증은 원문 접근 상태에 따라 달라지므로 단위 테스트에서 네트워크를 강제하지 않습니다. 배포 전 실제 키워드로 결과의 제목·가격·원문 URL을 확인합니다.

2026-11-01 검증: 로컬에서 중고물품 4개 서비스와 자동차 3개 서비스의 실제 응답을 확인했습니다. Vercel 배포에서는 중고물품 4개 서비스·KB차차차·K Car 응답을 확인했으나 엔카 연결은 실패했습니다. 원문 서비스가 배포 환경에서 응답하는지에 따라 검색 가능 범위가 달라지며, 현재 배포에서 7개 서비스가 모두 정상이라는 보장은 하지 않습니다. 연결 오류는 화면에 서비스별로 표시하고 성공한 결과는 유지합니다.

같은 날 클라우드 진단에서 엔카 공개 검색 요청의 HTTP 407을 확인했습니다. Node Fetch는 이 상태를 일반 네트워크 오류로 숨기므로 엔카 요청만 동일 URL의 표준 HTTPS GET으로 상태를 확인합니다. TLS 검증을 유지하고 리디렉션·재시도·인증 우회 없이 403/407/429를 `unavailable`로 표시합니다. 응답 크기는 2MB, 대기시간은 9초로 제한합니다. 이는 접근 제한 해제가 아니며 엔카의 배포 서버 수집은 아직 미해결입니다. 정식 데이터 이용 권한 또는 원문/중간 네트워크의 정책 확인이 필요합니다.

## 개인정보·디자인

아이폰의 주소창 없는 실행은 `display: standalone`으로 제공합니다. 실제 검색을 사용하는 홈 화면 아이콘은 `https://used-search-api.vercel.app/`에서 추가해야 합니다. 기존 GitHub Pages 아이콘은 시작 시 다른 도메인으로 이동하므로 iOS가 브라우저 컨트롤을 표시할 수 있습니다. 기존 아이콘의 설치 주소는 코드로 바꿀 수 없으며 새 아이콘을 추가해야 합니다. 홈의 ‘주소창 없이 앱으로 사용하기’가 올바른 설치 위치로 안내합니다. 외부 매물 원문은 브라우저 컨트롤이 나타날 수 있습니다. 같은 운영 주소 안에서 홈·검색·상세와 하단 메뉴를 이용합니다.

찜은 localStorage에만 저장되며 기기 간 동기화되지 않습니다. 검색어와 선택 서비스는 API와 원문 서비스에 전달됩니다. 위치·지역명·반경은 이 탭의 방문 기록에만 보관하고 외부로 보내지 않습니다. 구매·결제·채팅은 제공하지 않습니다. 토스 공개 디자인 원칙을 참고한 독립 UI이며 공식 TDS 패키지 또는 제휴 서비스는 아닙니다.

앱 manifest는 같은 출처에서 불러옵니다. 운영 주소의 홈 화면 아이콘은 로그인 없이 사용할 수 있습니다.

## 엔카 브라우저 직접 조회 복구

Vercel의 정상 검색 응답에서 엔카 연결 실패가 확인되면, 브라우저가 같은 엔카 공개 검색 API를 `credentials: omit`의 CORS GET으로 한 번 조회합니다. 요청은 9초·2MB로 제한하고 검색 취소/화면 이동 시 함께 취소합니다. 쿠키·인증정보·우회 프록시를 사용하지 않습니다. 성공한 실제 매물을 동일한 검증·중복 제거·키워드 필터를 거쳐 KB차차차/K Car 결과와 합치며, 실패하면 기존 결과와 서비스별 연결 안내를 유지합니다. API 접근 실패(401/403), 요청 제한(429), 잘못된 서버 응답일 때는 복구하지 않습니다. 서버 엔카 대기 중에도 공개 CORS 조회를 한 번 허용하되, 해당 브라우저의 조회가 실패하면 5분간 재시도를 멈춥니다.

2026-11-01 검증: USED Origin의 공개 API 응답이 `Access-Control-Allow-Origin: *`를 허용함을 확인했고, 실제 브라우저에서도 `xf` 요청이 CORS HTTP 200과 105건의 전체 수를 반환했습니다. 이는 해당 시점·검증 네트워크에서의 조회 성공이며 엔카 정책이나 사용자 네트워크에 따라 달라질 수 있습니다. 서버 경로의 407 자체를 해결한 것은 아닙니다.

로컬 통합 검증에서는 서버의 엔카 실패 응답만 재현하고, 엔카 브라우저 요청과 KB차차차/K Car 서버 요청은 실제 서비스에 연결했습니다. `xf`는 엔카 30개·KB차차차 18개·K Car 0개, `그랜저`는 엔카 29개·KB차차차 30개·K Car 30개가 동일 목록에 표시됐습니다. 자동 테스트 90개와 구문 검사를 통과했습니다. 보호된 운영 앱의 사용자 아이폰 환경은 별도 확인이 필요합니다.

## 현재 위치의 지역명

`현재 위치로 찾기`는 기기 GPS 좌표를 국내 행정구역 경계와 브라우저 안에서 비교합니다. 좌표를 URL, 검색 API, 외부 역지오코딩 서비스, 로그로 보내지 않습니다. GPS 모드의 지역명은 표시용이며 거리 필터에 같은 지역명 조건을 중복 적용하지 않습니다. 직접 입력하면 지역명 검색으로 전환합니다. 위치 조회 중 입력·시트 닫기·화면 이동은 진행 중 요청을 취소하고 늦은 응답을 버립니다. 위치·지역명·반경은 하나의 history snapshot으로 검증·복원합니다.

경계 자료는 `vuski/admdongkor` 2026-10-01 light, 전국 3,559개 읍면동입니다. 원자료는 통계청 SGIS 공공누리 제1유형, 가공 자료는 CC BY 4.0입니다. 출처·라이선스·변환 내역은 `assets/regions/`에 보존합니다. 약 1.97MB의 gzip 파일은 위치 조회 때 같은 출처에서 한 번 받아 이 기기에서 해제합니다. 최신 Safari 등 DecompressionStream 지원 브라우저가 필요합니다. 첫 사용 전 네트워크가 끊겼거나 지역명을 확인할 수 없으면 좌표 기반 검색과 안내를 유지하고 이름을 추정하지 않습니다. 데이터는 단순화된 행정동 경계이므로 법정동·도로명주소와 다르거나 경계 부근에 오차가 있을 수 있습니다.
